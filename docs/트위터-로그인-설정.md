# 트위터(X) 로그인 설정

코드는 이미 다 들어가 있습니다. 아래 설정을 마치고 **스위치만 켜면** 버튼이 나타납니다.

> ⚠️ 지금은 `public/palo.js`의 `TWITTER_LOGIN_ENABLED = false` 라서 버튼이 숨겨져 있습니다.
> 설정 전에 켜 두면 눌렀을 때 오류만 나므로 일부러 꺼 뒀습니다.

---

## 0단계. 비용을 먼저 아셔야 합니다

X는 **2026년 2월부터 신규 개발자에게 무료 티어를 주지 않습니다.**

| 항목 | 내용 |
|---|---|
| 요금 방식 | 종량제(선불 크레딧) |
| 최소 구매액 | 없음 (안 쓰면 0원) |
| 사용자 조회 | **1건당 $0.010** (공식 문서 기준) |

로그인할 때 X에서 프로필을 한 번 읽어오는데 그게 과금 대상입니다.
**한 번 로그인하면 세션이 유지되므로 재방문 때는 다시 부르지 않습니다.**

- 월 50회 로그인 → 약 700원
- 월 300회 로그인 → 약 4,200원

정확한 단가는 [개발자 콘솔](https://console.x.com)에서 확인하세요.

---

## 1단계. X 개발자 앱 만들기

1. https://developer.x.com 접속 → 개발자 계정 신청
2. 프로젝트와 앱 생성
3. 앱의 **User authentication settings** 에서 아래를 입력

| 칸 | 값 |
|---|---|
| App permissions | **Read** (읽기만 있으면 됨) |
| Type of App | **Web App** |
| Callback URI / Redirect URL | `https://<프로젝트ID>.supabase.co/auth/v1/callback` |
| Website URL | `https://commi.kr` |
| Terms of service | `https://commi.kr/terms` |
| Privacy policy | `https://commi.kr/privacy` |

> **Callback URL의 `<프로젝트ID>`**는 Supabase 대시보드 주소에 들어 있는 값입니다.
> Supabase → Settings → API 의 **Project URL** 을 그대로 쓰시면 됩니다.

4. **Request email from users** 를 **켜세요.** 꺼져 있으면 이메일을 못 받아 계정 생성이 막힐 수 있습니다.

---

## 2단계. 키 복사

앱 페이지의 **Keys and tokens** 로 가서 아래 두 개를 복사합니다.

- **Client ID**
- **Client Secret** (Regenerate 를 눌러야 보입니다 — 한 번만 보이니 바로 저장하세요)

> ⚠️ **OAuth 1.0a 쪽의 API Key / API Secret 이 아닙니다.**
> 우리는 OAuth 2.0을 쓰므로 **Client ID / Client Secret** 이어야 합니다.

---

## 3단계. Supabase에 넣기

1. Supabase 대시보드 → **Authentication → Providers**
2. 목록에서 **X / Twitter (OAuth 2.0)** 를 펼칩니다
   - ⚠️ 그냥 **Twitter (OAuth 1.0a)** 가 아니라 **(OAuth 2.0)** 이라고 적힌 쪽입니다. 1.0a는 곧 없어집니다.
3. **Enabled** 를 켜고 Client ID / Client Secret 입력 → **Save**

---

## 4단계. 스위치 켜기

`public/palo.js` 상단의

```js
var TWITTER_LOGIN_ENABLED=false;
```

를 `true` 로 바꾸고 배포하면 로그인 창에 **X로 로그인** 버튼이 나타납니다.

---

## 확인

로그인 창을 열어 X 버튼을 누르면 X 인증 화면으로 이동하고, 승인하면 commi로 돌아와 로그인됩니다.

닉네임은 X의 표시 이름으로 자동 생성되며, 회원이 나중에 바꿀 수 있습니다.

## 잘 안 될 때

| 증상 | 원인 |
|---|---|
| `redirect_uri_mismatch` | X 앱의 Callback URL이 Supabase 것과 한 글자라도 다름 |
| 승인 후 로그인이 안 됨 | Supabase의 Redirect URLs에 `https://commi.kr` 가 없음 (Authentication → URL Configuration) |
| 이메일 없다는 오류 | X 앱에서 **Request email from users** 가 꺼져 있음 |
| 크레딧 부족 오류 | 개발자 콘솔에서 크레딧 충전 필요 |
