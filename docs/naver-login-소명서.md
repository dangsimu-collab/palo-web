# commi 서비스 소개 및 소명 자료

**서비스명**: commi
**서비스 URL**: https://commi.kr
**서비스 형태**: 그림 창작자 커뮤니티 (웹 / 모바일 웹)
**로그인 방식**: 구글 계정, 네이버 계정(신청 중)

---

## 1. 서비스 개요

commi는 **그림을 그리는 사람들이 작업물을 공유하고 서로 피드백을 주고받는 창작 커뮤니티**입니다.

이용자는 자신이 그린 그림을 올려 감상평을 받고, 그림 실력에 대한 질문·자료를 나누며, 함께 그릴 사람을 찾습니다. 여기에 더해 **"커미션"(그림 의뢰) 정보를 서로 안내하는 게시 공간**을 제공합니다.

- 회원가입은 **만 14세 이상**만 가능하며, 가입 시 이용약관·개인정보처리방침에 필수 동의를 받습니다.
- 서비스 내 모든 콘텐츠는 **전 연령이 이용 가능한 일반 창작물**이며, **연령제한(성인) 콘텐츠는 제공하지 않습니다.** (자세한 내용은 4항)

## 2. 메뉴별 상세 설명

### 2-1. 게시판 (커뮤니티)

총 15개 게시판을 6개 그룹으로 운영합니다.

| 그룹 | 게시판 | 용도 |
|---|---|---|
| 이야기 | 전체 글 | 모든 게시판의 글을 최신순/인기순으로 모아 보는 화면 |
| | 수다 | 주제 제한 없는 자유 대화, 가입 인사 |
| 그리는 중 | 낙서 | 가볍게 그린 낙서·크로키 공유 (말머리: 낙서 / 크로키) |
| | 작업물 | 작업 중이거나 완성한 그림 공유 (말머리: 러프 / 선화 / 채색 / 완성) |
| | 그림공부 | 연습 과정·습작 공유 (말머리: 러프 / 선화 / 채색) |
| 궁금해요 | 질문/시세문의 | 그림 관련 질문, 커미션 가격대 문의 (말머리: 질문 / 시세문의) |
| | 투표/수요조사 | 그림 방향·수요를 묻는 투표 (본문에 투표 첨부 기능 제공) |
| | 피드백 요청 | 자신의 그림에 대한 조언 요청. 도움이 된 댓글을 **채택**하는 기능 제공 |
| 함께 | 협업/팀원모집 | 합작·팀 작업 상대 모집 (말머리: 협업 / 팀원모집) |
| | 챌린지 | 주제를 정해 함께 그리는 참여형 이벤트 (말머리: 참가작) |
| | 자료/TIP | 브러시·강좌 등 창작 자료 공유 (말머리: 강좌 / 꿀팁 / 자료) |
| 거래 | 리퀘스트 | "이런 그림 그려주세요" 요청·수락 (말머리: 모집중 / 모집완료 / 리퀘완료 / 후기글) |
| | 구인 | 그림 작업자를 찾는 글 (말머리: 개인용 / 비상업용 / 방송용 / 상업용 / 외주) |
| | 중고 | 타블렛 등 그림 장비 중고 거래 글 (말머리: 판매 / 구매) |
| 기타 | 버그·건의사항 | 서비스 오류 제보·개선 제안 (말머리: 버그 / 건의 / 개선) |

**게시판 공통 기능**: 글 작성(서식·이미지 첨부·투표 삽입), 댓글·답글, 추천, 조회수, 말머리 필터, 검색, 목록형/앨범형 보기 전환, 신고

### 2-2. 커미션 (네이버 검수 요청 항목)

**"커미션"이란** 그림 창작자에게 원하는 그림을 의뢰하는 창작 문화를 말합니다. commi는 창작자와 의뢰자가 **서로를 찾고 정보를 확인할 수 있는 게시 공간**을 제공합니다.

| 화면 | 설명 |
|---|---|
| 커미션 목록 | 등록된 커미션을 추천/신규/인기 순으로 열람. 태그·검색으로 탐색 |
| 커미션 상세 | 작가 소개, 예시 이미지, 작업 종류, 안내 사항, 거래 정책, 받은 후기 확인. 찜하기 가능 |
| 커미션 등록 | 창작자가 자신의 커미션 정보를 등록·수정·마감 처리 |
| 커미션 신청 | 의뢰자가 신청서를 작성해 문의 → 서비스 내 1:1 채팅으로 연결 |
| 커미션 후기 | 거래 경험을 만족/불호로 남김. 후기 통계가 작가 프로필에 표시 |
| 내 커미션 | 내가 등록한 커미션과 받은 신청 관리 |

**작업 종류 분류**: 두상, 흉상, 반신, 전신, SD(간략화 캐릭터), 이모티콘, 배경, 기타

> **중요 — 결제 미제공**
> commi는 **결제·에스크로(대금예치) 기능을 일절 제공하지 않습니다.** 회사는 정보 게시 공간만 제공하는 **통신판매중개자**이며, 대금 지급·작업 진행·환불 등 거래 이행은 전적으로 이용자 당사자 간에 이루어집니다. 이 내용은 서비스 하단(푸터)과 커미션 상세 화면의 "거래 정책 안내"에 상시 고지하고 있습니다.

### 2-3. 그 밖의 기능

- **1:1 채팅**: 커미션 문의·협업 논의를 위한 회원 간 대화
- **프로필**: 닉네임, 소개글, SNS 링크, 활동 점수·등급, 팔로잉/팔로워, 내가 쓴 글·좋아요·최근 본 글
- **알림**: 댓글·추천·채팅·공지 등에 대한 웹 푸시 알림 (항목별 수신 설정 가능)
- **관리자 페이지**: 신고 처리, 글 관리, 회원 관리, 통계 (운영자 전용)

## 3. 그림 유형 (게시되는 콘텐츠의 성격)

commi에 게시되는 그림은 다음과 같은 **일반 창작물**입니다.

- 캐릭터 일러스트 (오리지널 창작 캐릭터, 팬아트)
- 낙서·크로키 등 연습 그림, 습작
- 작업 과정 공유물 (러프 → 선화 → 채색 → 완성)
- SD(간략화) 일러스트, 이모티콘
- 배경·풍경 일러스트
- 창작 관련 자료 (브러시, 강좌 자료 등)

## 4. 연령제한 콘텐츠 제공 여부

**commi는 연령제한(성인) 콘텐츠를 제공하지 않습니다.**

- 서비스 내에 성인 전용 게시판·카테고리를 **운영하지 않습니다.**
- **이용약관에서 음란·선정적 표현물의 게시를 명시적으로 금지**하고 있으며, 위반 시 게시물 삭제 및 이용 제한 조치를 합니다.
- 회원가입은 **만 14세 이상**만 가능하며(개인정보처리방침 제4조), 만 14세 미만 아동의 개인정보는 수집하지 않습니다.
- 커미션 게시 역시 일반 창작 그림을 대상으로 하며, 성인물 의뢰·거래를 목적으로 하는 게시는 금지 대상입니다.

## 5. 부적절한 콘텐츠 관리 정책 및 시스템

### 5-1. 사전 안내 (게시 전)

1. **이용약관·개인정보처리방침 필수 동의** — 가입 시 동의 없이는 서비스 이용 불가
2. **커뮤니티 이용 규칙 상시 공지** — 서비스 첫 화면 상단에 고정 노출
   - 인신공격·조롱·저격 금지
   - 타인의 그림 도용·무단 재업로드 금지
   - 음란·선정적 표현물 게시 금지
   - **AI 생성 이미지 게시 전면 금지** (창작자 보호를 위한 자체 정책)
3. **게시판별 안내 문구** — 글쓰기 화면에서 해당 게시판의 용도를 안내해 목적 외 게시를 예방

### 5-2. 이용자 신고 및 운영자 처리 (게시 후)

4. **신고 기능** — 모든 게시물·댓글·채팅·광고에 신고 버튼 제공
5. **관리자 신고 처리 화면** — 접수된 신고를 운영자가 검토 후 삭제·경고·이용제한 조치
6. **삭제 기록 보관** — 운영자가 삭제한 게시물은 원문 스냅샷·삭제 사유·처리 시각·처리자와 함께 보관되어 사후 확인이 가능
7. **회원 이용 제한(차단)** — 위반 회원의 서비스 이용을 차단하며, **재가입을 통한 제재 회피를 방지**하는 장치를 적용

### 5-3. 자동 방지 장치

8. **도배 방지** — 회원별·IP별 게시 빈도 제한(rate limit)을 서버에서 적용
9. **비회원 작성 글의 IP 일부 표시** — 자작·도배 행위 억제
10. **후기 조작 자동 감지** — 비정상적인 후기 패턴을 자동 분석해 운영자에게 통보
11. **광고 사전 심사** — 이용자가 게시하는 광고는 운영자 승인 후에만 노출
12. **데이터 접근 통제** — 데이터베이스 단에서 행 단위 접근 권한(RLS)을 적용해 타인의 정보 접근을 차단

### 5-4. 거래 관련 고지

13. **통신판매중개자 고지** — 서비스 하단에 상시 표시
14. **거래 정책 안내** — 커미션 상세 화면에서 "회사는 거래 당사자가 아니며 결제를 중개하지 않는다"는 점과 분쟁 시 책임 소재를 명시
